# Plane Game Realistic

A JavaScript 3D plane dogfight demo with:

- Bullet drop and gravity for projectiles
- Realistic plane movement (energy, throttle, speed-altitude tradeoff)
- OBJ/MTL model support (see the assets folder)
- Menu and minimal HUD using your image/UI assets

## Controls
- Throttle: **SHIFT** (increase), **CTRL** (decrease)
- Flight: **WASD** or arrow keys
- Fire: **Space**
- Menu: **Click** or **Esc**

## Models & UI
All OBJ/MTL assets and images go in the `assets/` directory as seen in this repo.
